# 这个 AI 学习博客是怎么搭起来的

今天把博客的第一版搭好了。以后每周写一篇，把这一周学到的东西、做过的实验和遇到的问题记下来。

## 为什么做它

我想学习 AI Agent 开发，也想把过程留下来。博客不用很复杂，能方便地写文章、看到结果，就够了。

## 它现在能做什么

- 用 Markdown 写文章
- 在首页按标签筛选和搜索
- 点击卡片直接阅读文章
- 推送到 GitHub 后自动部署到 GitHub Pages

## 我准备怎么用

每周选一个小主题，写下本周做了什么、哪里没弄懂、下周准备试什么。先把节奏保持住，再慢慢把内容做深。

```text
write → build → push → repeat
```
