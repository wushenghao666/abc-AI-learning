# 我的 8 周 AI 学习计划

mentor 给我的方向是：先做出一个有具体用途的深度学习模型，再了解大模型和 Agent 开发。底层原理了解清楚基本流程即可，学习重点放在框架使用和实际项目上。

我准备以周为单位推进。每周确定一个主题，周末整理一次学习内容和成果。

## 第 1 周：熟悉 PyTorch，跑通第一次训练

这一周先不追求复杂模型，也不急着手写神经网络。目标是看懂并跑通一套完整的训练流程。

需要学习的内容：

- 张量是什么，以及常用的张量操作
- 数据集、DataLoader 和批量训练
- 模型、损失函数和优化器分别做什么
- 前向传播、反向传播和参数更新的基本过程
- 训练集、验证集和测试集的区别

本周项目使用 Fashion-MNIST 数据集，先完成一个简单的服饰图像分类模型。建议先用全连接网络跑通，再尝试换成一个小型 CNN。

本周成果：

- 一份可以直接运行的 PyTorch 训练代码
- 测试集准确率和训练损失
- 几张预测正确与预测错误的样例
- 一篇简短复盘：模型做了什么、效果如何、还存在哪些问题

## 第 2 周：改进图像分类模型

在第一周模型的基础上继续实验，学习 CNN、数据增强、过拟合和基本评估方法。比较不同模型或参数的结果，不需要盲目追求很高的准确率。

本周成果：改进后的 CNN、训练曲线，以及一次实验对比。

## 第 3 周：做一个更接近实际用途的模型

选择一个自己感兴趣的小数据集，例如猫狗分类、垃圾分类、花卉分类或其他图像识别任务。学习迁移学习，使用预训练模型完成训练。

本周成果：一个针对具体问题的图像分类模型，以及独立测试图片的预测结果。

## 第 4 周：整理并展示深度学习项目

完善数据处理、模型保存和推理代码，补充失败案例。可以用 Gradio 做一个简单的本地演示页面，让别人上传图片并看到预测结果。

本周成果：第一个可以演示的深度学习项目，以及一篇完整的项目总结。

## 第 5 周：开始使用大模型 API

学习大模型 API 的基本调用、消息结构、提示词和结构化输出。先做一个小工具，例如文本总结、信息提取或学习笔记整理器。

本周成果：一个可以稳定接收输入并返回结果的大模型小工具。

## 第 6 周：学习 RAG

了解文本切分、向量表示、检索和生成的基本流程。用自己的几篇学习笔记做一个简单的问答程序，并观察它在哪些问题上容易答错。

本周成果：一个能够查询个人学习资料的问答程序。

## 第 7 周：做第一个 Agent

学习 Agent 的基本组成：模型、工具、状态和循环。先让 Agent 使用一到两个简单工具，例如读取本地资料、进行计算或整理文件。

本周成果：一个能根据任务选择工具并完成简单工作的 Agent。

## 第 8 周：完成最终项目与总结

把前几周学到的内容整合成一个小项目。重点处理错误情况、补充测试、整理使用说明，并回顾八周中真正掌握了什么。

本周成果：最终项目、演示说明和八周学习总结。

## 现在从哪里开始

第一步是配置 Python 与 PyTorch 环境，然后完成 PyTorch 官方入门教程中的张量、数据加载和训练部分。环境跑通后，马上开始 Fashion-MNIST，不需要等所有理论都学完。

第一周只需要回答三个问题：

1. 数据是怎样送进模型的？
2. 模型是怎样根据错误更新参数的？
3. 怎样判断模型有没有学到东西？

能用自己的代码跑通训练，并解释这三个问题，第一周的目标就完成了。
